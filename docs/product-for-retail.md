# Trade Nothing：面向散户的认知组合管理工具

## 一句话定位

不是荐股工具，不是行情软件，不是新闻推送——**它把你的投资判断当作持仓来管理：帮你查证、帮你避坑、帮你记住、帮你复盘。**

## 散户真正缺什么

散户对机构的劣势从来不是"不够勤奋"，而是三件事：

1. **信息验证**：机构有研究员核对公告原文，散户靠自媒体标题；
2. **认知存续**：机构有投研数据库，散户的研究在报告看完那一刻就开始贬值；
3. **决策复盘**：机构有风控台账，散户亏了钱不知道自己错在哪条链上。

Trade Nothing 只针对这三件事。

## 五个功能场景

### 场景一：模糊问题深研——"这个题材是真的吗？"
你说："金刚光伏的太空光伏和算力转型怎么看？"

工具输出：
- **根结论**：太空光伏 = 纯题材映射（公司官方口径连"送样"都没确认）；算力 = 真实合同但收入/客户/审计三关未过
- **可能性地图**：多头/基准/空头路径，每条标出承重主张和最弱环节
- **定价对照表**：市场已定价什么、未定价什么（124 亿市值里"太空"值多少）
- **陷阱检查**：逐条对照七条常见错误共识
- **下一步**：8/24 半年报看哪三个科目、每条对应哪条锚

### 场景二：触发日轻量更新——"我的判断还成立吗？"
8/24 中报出来了。你只说一句：**"更新锚"**。

工具花几分钟查完触发器里写好的科目（应收/合同负债/毛利），告诉你：
- 锚 2"合同收入确认是 H2 最大验证项"→ 升档为 FACT 支持，或标 [失效] 并记录推翻它的事实
- 不用重读旧报告，不用重新研究一遍

### 场景三：每日观察（自动）——下班后三分钟
每个工作日 18:30 自动运行，产出：
- 一句话市场判断 + 三条真实变化（每条带证据标签和来源）
- 一个值得研究的选题 + 建议预算
- 锚体检：哪条认知锚的触发条件到期/临近了

### 场景四：每周复盘（周五）——"我错在哪"
- 决策日志对照：当时信了什么、做了什么、对不对
- 失效锚统计：你的错误集中在哪条陷阱（错误贝斯率）
- 给研究方法的修正建议（若某条陷阱连续命中）

### 场景五：认知跨主题复用——教训不重犯
华丰科技"官方口径 vs 市场传闻"的教训自动存进锚库；下次审查金刚光伏"送样"传闻时，这条教训自动套用——**你的认知不随单个报告过期**。

## 六项能力

| 能力 | 说明 | 实证 |
|---|---|---|
| **查证** | 上市公司先枚举官方披露索引；官方口径与传闻冲突必标红 | 金刚光伏"送样"实为媒体单源 |
| **避坑** | 七条陷阱清单，来自六个冻结案例的错误共识规律 | "需求增长≠便宜"、"预披露≠最终法" |
| **定价意识** | "真不真"与"贵不贵"分开；每个价格锚必须说明什么预期差让它有吸引力 | 盲评价格锚定有效 3.2 倍于基线 |
| **记忆** | 认知锚库：可证伪命题 + 证据等级 + 更新触发器；失效保留不删除 | 10 条锚跨两个主题持续更新 |
| **纪律** | 只到研究为止；拿不到的事实明说拿不到（NO_RESULT 带边界） | 不编造、不回填 |
| **自我进化** | 冻结基准 + 盲评协议：每次改进先过盲评再发布 | 两项 A/B 门槛全部通过 |

## 如何用起来（三步）

**第一天（零门槛）**：直接在 Codex / Claude / Gemini 里问一个你关心的问题。工具自动接管：可能性地图 → 证据猎取 → 报告 + 认知锚。看报告最后面的"证据表"和"下一步验证"，感受一下"每个结论都能回溯到来源"是什么体验。

**第一周（形成节奏）**：
- 每天 18:30 看每日观察消息（三条变化 + 选题 + 锚提醒）
- 遇到锚触发提醒，说一句"更新锚"
- 把你真正想深研的问题攒下来，一次问一个

**第一个月（开始复利）**：
- 每周五跑一次周复盘，看自己最常踩哪条坑
- 三个月后回看 `anchors/`：你的认知库里有几条升档、几条失效——失效的教训比赚钱的运气值钱

## 诚实的边界

- **不荐股、不下单、不设仓位、不承诺回报**——它止步于研究和判断的维护
- 认知锚需要你来触发更新（提醒会到，检查是你的一句话）
- 工具帮你把"感觉"变成"可验证的判断"，但**判断之后的行为永远是你自己的**

## 与常见工具的区别

| 工具 | 给你什么 | 缺陷 |
|---|---|---|
| 荐股/投顾 | 买卖建议 | 不告诉你为什么错，不可复盘 |
| 行情软件 | 数据 | 没有判断，更没有判断的更新 |
| 财经新闻 | 信息流 | 标题党多，不帮你验证 |
| 大模型裸问 | 一次性答案 | 不记得上次说过什么，不负责下次更新 |
| **Trade Nothing** | **可验证的判断 + 会生长的认知** | 需要你偶尔说一句"更新锚" |
