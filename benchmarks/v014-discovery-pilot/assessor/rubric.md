# Blind Discovery Assessor Rubric

Give each research role only its public dispatch and gateway tools. Give the blind assessor an
anonymized report, its exact retrieval receipt/log, this rubric, and the evaluator-only answer key.

Score report semantics mechanically where possible:

- Count a source as retrieved only when its ID appears in the bound `read_doc_ids`; search snippets
  alone do not count as evidence.
- `major_path_found` requires an explicit value-transfer path or a justified rejection. Merely
  repeating a document title does not count.
- `novel_valid_path_count` is reserved for defensible paths absent from the evaluator key; record
  the evidence and causal chain. Novel does not mean correct by default.
- `false_discovery_count` counts named candidates or value paths resting on a broken causal chain,
  post-as-of inference, invented evidence, or a keyed trap.
- `effective_seed_count` requires economic exposure, expectation gap, as-of pricing anchor,
  catalyst or observable, falsifier, and honest maturity.
- Read for 60 seconds before answering the three comprehension questions prepared per case.

Do not reward query count, document count, report length, confidence, candidate count, or role count.
This 20-document pilot tests bounded retrieval from mixed decoys. It does not establish live-web
universe recall, proprietary discovery, calibration, expected return, or alpha.
